# Ranger USD (rgUSD)

## Overview

Ranger USD (rgUSD) is a liquid yield-bearing token designed to deliver simple one-click yield from institutional trading strategies. It is a boosted yield aggregator that combines Solana's best lending yields with opportunistic delta-neutral funding rate farming to deliver consistent higher lending returns with instant withdrawals.

rgUSD holders automatically earn yield without needing to lock funds or manage complex DeFi positions.
